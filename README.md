# AKA-DENT

Двуязычный сайт стоматологии AKA-DENT для публикации на GitHub Pages.

## Публичная демо-версия

- Сайт: https://02td.github.io/AKA-DENT/
- Панель: https://02td.github.io/AKA-DENT/aka-office/
- Альтернативная ссылка панели: https://02td.github.io/AKA-DENT/clinic-panel/

Демо-версия не зависит от ChatGPT/Sites. Заявки, изменения цен, отзывы и загруженные фотографии сохраняются в localStorage текущего браузера. Это позволяет клиенту свободно проверить интерфейс, но данные не синхронизируются между разными устройствами.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

После запуска откройте адрес, показанный в терминале.

## Публикация

Каждый push в ветку `main` автоматически собирает и публикует сайт через GitHub Actions. Для боевой версии с общей базой заявок и защищённой админ-панелью нужен отдельный сервер или облачная база данных.
